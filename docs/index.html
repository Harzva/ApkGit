它不是另一个封闭应用商店，而是补齐开源仓库、Release 资产、下载验证和本地安装之间缺失的展示层。

发现

按平台和类别浏览，也可以输入仓库地址直接检查 Release 资产。

校验

展示上游仓库、许可证、源代码地址、SHA256、下载量和签名指纹规划位。

下载

不托管、不重签、不修改第三方二进制，只链接官方 Release 文件。

合规底线写在前面。

  • GitMarket 不是安全审核机构，也不保证第三方软件绝对安全。
  • 下载链接来自上游 GitHub/Gitee Release，不托管 APK、EXE、IPA 等文件。
  • 后续版本会前置展示 SHA256、签名指纹、许可证、源码地址和签名变更警告。
  • GitHub Token 是可选项，只用于提高 API 频率限制，桌面端应改用系统凭据存储。
