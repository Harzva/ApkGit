GitHub/Gitee Release APK discovery

GitHub 上的开源 APK，一眼找到。

ApkGit 是一个桌面优先的开源工具，帮助开源爱好者从上游 Release 中发现 APK、查看元数据、下载原始文件，并把安全校验放到用户看得见的位置。

先做可信的链路。

产品不试图变成另一个封闭应用商店，而是把 GitHub Release 到本地下载之间的断层补齐。

01

发现

输入仓库或从策展列表进入，直接查看可下载的 APK Release 资产。

02

检查

展示上游仓库、Release、文件大小、下载量、预发布状态和校验信息。

03

下载

只从上游 Release URL 下载，不托管、不重签、不修改第三方 APK。

安全边界写在前面。

  • ApkGit 不是 APK 审核机构，也不保证第三方 APK 安全。
  • 下载链接来自上游 GitHub/Gitee Release。
  • 后续版本会把 SHA256、签名指纹、许可证和签名变更警告前置展示。
  • GitHub Token 是可选项，只用于提高 API 频率限制。

路线清楚，节奏克制。

  • 0.1：桌面 MVP，跑通仓库解析、APK 列表、下载和 SHA256。
  • 0.2：许可证、签名指纹、下载历史和风险提示。
  • 0.3：多仓库管理、策展目录、基础热榜。
  • Android 原生 MVP：单独用 Kotlin + Jetpack Compose 推进。
