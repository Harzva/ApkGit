GitMarket 移动端本地预览

这个 HTML 可以直接本地打开，用来预演移动端主题、状态、布局和文案；正式 Android 产物只保留 Rust/egui experimental APK。

为什么这样做

发布包最后仍然需要真机检查，但日常 UI、文案、主题、状态流和列表密度可以先在本地 HTML 里快速迭代，减少反复安装 APK 或 IPA 的时间。

1
真实 WebView 预览 WebView 模式只用于核对 GitHub Pages 搜索台，不再对应单独发布的 preview APK。
2
原生界面预演 把移动端主题、双语、底部导航、下载、安全和多来源搜索先做成可点的产品稿。
3
最终真机验收 当 HTML 预览确认后，再触发 CI 打包，在 Android 或 iOS 设备上做少量关键路径验收。
